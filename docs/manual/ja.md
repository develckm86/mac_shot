# ScreenCapture 0.4.4 — ショートカット

通知領域に常駐します。ウインドウは開きません。

## ショートカット

| | |
| --- | --- |
| `Ctrl+Shift+3` | 画面全体をキャプチャ — ディスプレイごとに 1 ファイル |
| `Ctrl+Shift+4` | ドラッグして範囲をキャプチャ — Space でウインドウ選択 |
| `Ctrl+Shift+5` | スクリーンショットツール — ウインドウ撮影・画面収録・オプション |
| `Ctrl+Alt+Shift+3 / 4` | クリップボード |
| `Ctrl+Alt+Esc` | 収録を停止 |

## ドラッグ中に使えるキー

| | |
| --- | --- |
| `Space` | 大きさを保ったまま選択範囲を動かす |
| `Shift` | 最後に動かした軸だけが変わる |
| `Alt` | 始点を中心に上下左右へ広がる |
| `Ctrl` | 離すときに押していればファイルではなくクリップボードへ |
| `Esc` | キャンセル |

## オプション — `Ctrl+Shift+5` → オプション

- **保存先**: デスクトップ · ドキュメント · クリップボード · ピクチャ · その他の場所…
- **タイマー**: なし · 5 秒 · 10 秒
- **マイク**: なし · …
- **オプション**: フローティングサムネールを表示 · 最後の選択範囲を記憶 · マウスポインタを表示 · マウスクリックを表示 · 毎回保存先を確認
- **言語**: システムの言語 · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어

## 保存されるファイル名

```
Screenshot 2026-08-27 at 5.36.12 PM.png
Screen Recording 2026-08-27 at 5.36.12 PM.mp4
```

## 広告

このアプリは無料で、キャプチャ後に画面隅へ小さなバナーが少しの間表示されます。✕ で閉じられます。
