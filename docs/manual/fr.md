# MacStyleCapture 0.4.6 — Raccourcis

Reste dans la zone de notification. Aucune fenêtre ne s'ouvre.

## Raccourcis

| | |
| --- | --- |
| `Ctrl+Shift+3` | Capturer tout l'écran — un fichier par écran |
| `Ctrl+Shift+4` | Glissez pour capturer une zone — Space choisit une fenêtre |
| `Ctrl+Shift+5` | Outils de capture — fenêtre, enregistrement, options |
| `Ctrl+Alt+Shift+3 / 4` | Presse-papiers |
| `Ctrl+Alt+Esc` | Arrêter l'enregistrement |

## Touches à maintenir pendant le glissement

| | |
| --- | --- |
| `Space` | Déplace la sélection sans changer sa taille |
| `Shift` | Seul le dernier axe déplacé change |
| `Alt` | Redimensionne symétriquement autour du point de départ |
| `Ctrl` | Maintenue au relâchement : va dans le presse-papiers, pas dans un fichier |
| `Esc` | Annuler |

## Options — `Ctrl+Shift+5` → Options

- **Enregistrer dans**: Bureau · Documents · Presse-papiers · Images · Autre emplacement…
- **Minuteur**: Aucun · 5 secondes · 10 secondes
- **Microphone**: Aucun · …
- **Options**: Afficher la vignette flottante · Mémoriser la dernière sélection · Afficher le pointeur · Afficher les clics de souris · Demander où enregistrer
- **Langue**: Langue du système · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어
