# MacStyleCapture 0.4.6 — 快捷键

常驻通知区域，不会打开窗口。

## 快捷键

| | |
| --- | --- |
| `Ctrl+Shift+3` | 截取整个屏幕 — 每台显示器一个文件 |
| `Ctrl+Shift+4` | 拖动截取区域 — 按 Space 选择窗口 |
| `Ctrl+Shift+5` | 截图工具 — 窗口截图、录屏、选项 |
| `Ctrl+Alt+Shift+3 / 4` | 剪贴板 |
| `Ctrl+Alt+Esc` | 停止录制 |

## 拖动时可用的按键

| | |
| --- | --- |
| `Space` | 保持大小不变，移动选区 |
| `Shift` | 只改变最后移动的那个方向 |
| `Alt` | 以起点为中心向四周对称缩放 |
| `Ctrl` | 松开时按住则复制到剪贴板，不保存文件 |
| `Esc` | 取消 |

## 选项 — `Ctrl+Shift+5` → 选项

- **保存到**: 桌面 · 文档 · 剪贴板 · 图片 · 其他位置…
- **定时器**: 无 · 5 秒 · 10 秒
- **麦克风**: 无 · …
- **选项**: 显示浮动缩略图 · 记住上次选区 · 显示鼠标指针 · 显示鼠标点击 · 每次询问保存位置
- **语言**: 系统语言 · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어

## 保存的文件名

```
Screenshot 2026-08-27 at 5.36.12 PM.png
Screen Recording 2026-08-27 at 5.36.12 PM.mp4
```

## 广告

本应用免费，截图完成后会在屏幕角落短暂显示一个小横幅。点击 ✕ 关闭。
