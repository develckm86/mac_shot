# MacStyleCapture 0.4.6 — Phím tắt

Nằm ở khay hệ thống. Không mở cửa sổ nào.

## Phím tắt

| | |
| --- | --- |
| `Ctrl+Shift+3` | Chụp toàn màn hình — mỗi màn hình một tệp |
| `Ctrl+Shift+4` | Kéo để chụp một vùng — Space để chọn cửa sổ |
| `Ctrl+Shift+5` | Công cụ chụp — chụp cửa sổ, quay màn hình, tùy chọn |
| `Ctrl+Alt+Shift+3 / 4` | Bảng nhớ tạm |
| `Ctrl+Alt+Esc` | Dừng quay |

## Phím có thể giữ khi kéo

| | |
| --- | --- |
| `Space` | Di chuyển vùng chọn mà không đổi kích thước |
| `Shift` | Chỉ trục vừa di chuyển thay đổi |
| `Alt` | Thay đổi kích thước đối xứng quanh điểm bắt đầu |
| `Ctrl` | Giữ khi thả: vào bảng nhớ tạm thay vì tệp |
| `Esc` | Hủy |
