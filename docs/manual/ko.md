# 스크린샷 0.3.0 — 단축키

트레이에 상주합니다. 창은 뜨지 않습니다.

## 단축키

| | |
| --- | --- |
| `Ctrl+Shift+3` | 전체 화면 캡처 — 디스플레이마다 파일 하나 |
| `Ctrl+Shift+4` | 부분 캡처 — 끌어서 선택, Space 로 창 선택 |
| `Ctrl+Shift+5` | 스크린샷 도구 — 창 캡처·화면 기록·옵션 |
| `Ctrl+Alt+Shift+3 / 4` | 클립보드 |
| `Ctrl+Alt+Esc` | 기록 정지 |

## 드래그 중에 쓰는 키

| | |
| --- | --- |
| `Space` | 선택 크기를 유지한 채 위치를 옮긴다 |
| `Shift` | 마지막으로 움직인 축 하나만 바뀐다 |
| `Alt` | 시작한 점을 중심으로 사방 대칭 확대 |
| `Ctrl` | 놓는 순간 눌려 있으면 파일 대신 클립보드로 |
| `Esc` | 취소 |

## 옵션 — `Ctrl+Shift+5` → 옵션

- **마이크**: 없음 · …

- **언어**: 시스템 언어 · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어
