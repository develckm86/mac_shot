# ScreenCapture 0.4.4 — Shortcuts

Lives in the tray. No window opens.

## Shortcuts

| | |
| --- | --- |
| `Ctrl+Shift+3` | Capture the whole screen — one file per display |
| `Ctrl+Shift+4` | Drag to capture a region — Space picks a window |
| `Ctrl+Shift+5` | Screenshot tools — window capture, recording, options |
| `Ctrl+Alt+Shift+3 / 4` | Clipboard |
| `Ctrl+Alt+Esc` | Stop recording |

## Keys you can hold while dragging

| | |
| --- | --- |
| `Space` | Move the selection without changing its size |
| `Shift` | Only the last axis you moved changes |
| `Alt` | Resize symmetrically around the starting point |
| `Ctrl` | Held when you release: goes to the clipboard, not a file |
| `Esc` | Cancel |

## Options — `Ctrl+Shift+5` → Options

- **Save to**: Desktop · Documents · Clipboard · Pictures · Other Location…
- **Timer**: None · 5 Seconds · 10 Seconds
- **Microphone**: None · …
- **Options**: Show Floating Thumbnail · Remember Last Selection · Show Mouse Pointer · Show Mouse Clicks · Ask Where to Save
- **Language**: System language · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어
