# 스크린샷 0.3.0 — Сочетания клавиш

Живёт в области уведомлений. Окно не открывается.

## Сочетания клавиш

| | |
| --- | --- |
| `Ctrl+Shift+3` | Снимок всего экрана — по файлу на каждый монитор |
| `Ctrl+Shift+4` | Потяните, чтобы снять область — Space выбирает окно |
| `Ctrl+Shift+5` | Инструменты — снимок окна, запись экрана, параметры |
| `Ctrl+Alt+Shift+3 / 4` | Буфер обмена |
| `Ctrl+Alt+Esc` | Остановить запись |

## Клавиши, которые можно держать при перетаскивании

| | |
| --- | --- |
| `Space` | Переместить выделение, не меняя размер |
| `Shift` | Меняется только последняя изменённая ось |
| `Alt` | Изменять размер симметрично от начальной точки |
| `Ctrl` | Удерживать при отпускании — в буфер обмена, а не в файл |
| `Esc` | Отмена |

## Параметры — `Ctrl+Shift+5` → Параметры

- **Сохранять в**: Рабочий стол · Документы · Буфер обмена · Изображения · Другое расположение…
- **Таймер**: Нет · 5 секунд · 10 секунд
- **Микрофон**: Нет · …
- **Параметры**: Показывать плавающую миниатюру · Запоминать последнюю область · Показывать указатель · Показывать щелчки мыши · Спрашивать, куда сохранять
- **Язык**: Язык системы · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어
