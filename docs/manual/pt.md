# ScreenCapture 0.4.4 — Atalhos

Fica na bandeja. Nenhuma janela é aberta.

## Atalhos

| | |
| --- | --- |
| `Ctrl+Shift+3` | Capturar a tela inteira — um arquivo por monitor |
| `Ctrl+Shift+4` | Arraste para capturar uma área — Space escolhe uma janela |
| `Ctrl+Shift+5` | Ferramentas — captura de janela, gravação, opções |
| `Ctrl+Alt+Shift+3 / 4` | Área de transferência |
| `Ctrl+Alt+Esc` | Parar a gravação |

## Teclas que dá para segurar ao arrastar

| | |
| --- | --- |
| `Space` | Move a seleção sem mudar o tamanho |
| `Shift` | Só muda o último eixo que você moveu |
| `Alt` | Redimensiona simetricamente a partir do ponto inicial |
| `Ctrl` | Segurada ao soltar: vai para a área de transferência, não para um arquivo |
| `Esc` | Cancelar |

## Opções — `Ctrl+Shift+5` → Opções

- **Salvar em**: Área de trabalho · Documentos · Área de transferência · Imagens · Outro local…
- **Temporizador**: Nenhum · 5 segundos · 10 segundos
- **Microfone**: Nenhum · …
- **Opções**: Mostrar miniatura flutuante · Lembrar a última seleção · Mostrar o ponteiro · Mostrar cliques do mouse · Perguntar onde salvar
- **Idioma**: Idioma do sistema · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어
