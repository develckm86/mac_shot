# 스크린샷 0.3.0 — Kurzbefehle

Läuft im Infobereich. Es öffnet sich kein Fenster.

## Kurzbefehle

| | |
| --- | --- |
| `Ctrl+Shift+3` | Ganzen Bildschirm aufnehmen — eine Datei pro Anzeige |
| `Ctrl+Shift+4` | Bereich ziehen — mit Space ein Fenster wählen |
| `Ctrl+Shift+5` | Screenshot-Werkzeuge — Fenster, Aufzeichnung, Optionen |
| `Ctrl+Alt+Shift+3 / 4` | Zwischenablage |
| `Ctrl+Alt+Esc` | Aufzeichnung beenden |

## Tasten, die beim Ziehen helfen

| | |
| --- | --- |
| `Space` | Auswahl verschieben, Größe bleibt gleich |
| `Shift` | Nur die zuletzt bewegte Achse ändert sich |
| `Alt` | Symmetrisch um den Startpunkt vergrößern |
| `Ctrl` | Beim Loslassen gedrückt: in die Zwischenablage statt in eine Datei |
| `Esc` | Abbrechen |

## Optionen — `Ctrl+Shift+5` → Optionen

- **Speichern unter**: Desktop · Dokumente · Zwischenablage · Bilder · Anderer Ort…
- **Timer**: Keiner · 5 Sekunden · 10 Sekunden
- **Mikrofon**: Keiner · …
- **Optionen**: Schwebende Miniatur anzeigen · Letzte Auswahl merken · Mauszeiger anzeigen · Mausklicks anzeigen · Immer nach Speicherort fragen
- **Sprache**: Systemsprache · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어

## Dateinamen

```
Screenshot 2026-08-27 at 5.36.12 PM.png

```

## Anzeige

Diese App ist kostenlos und zeigt nach einer Aufnahme kurz ein kleines Banner in der Ecke. Mit ✕ schließen.
