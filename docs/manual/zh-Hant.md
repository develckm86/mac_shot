# MacStyleCapture 0.4.6 — 快速鍵

常駐通知區域，不會開啟視窗。

## 快速鍵

| | |
| --- | --- |
| `Ctrl+Shift+3` | 擷取整個螢幕 — 每台顯示器一個檔案 |
| `Ctrl+Shift+4` | 拖曳擷取區域 — 按 Space 選擇視窗 |
| `Ctrl+Shift+5` | 截圖工具 — 視窗擷取、螢幕錄製、選項 |
| `Ctrl+Alt+Shift+3 / 4` | 剪貼簿 |
| `Ctrl+Alt+Esc` | 停止錄製 |

## 拖曳時可用的按鍵

| | |
| --- | --- |
| `Space` | 保持大小不變，移動選取範圍 |
| `Shift` | 只改變最後移動的那個方向 |
| `Alt` | 以起點為中心向四周對稱縮放 |
| `Ctrl` | 放開時按住則複製到剪貼簿，不儲存檔案 |
| `Esc` | 取消 |

## 選項 — `Ctrl+Shift+5` → 選項

- **儲存到**: 桌面 · 文件 · 剪貼簿 · 圖片 · 其他位置…
- **計時器**: 無 · 5 秒 · 10 秒
- **麥克風**: 無 · …
- **選項**: 顯示浮動縮圖 · 記住上次選取範圍 · 顯示滑鼠指標 · 顯示滑鼠點擊 · 每次詢問儲存位置
- **語言**: 系統語言 · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어

## 儲存的檔名

```
Screenshot 2026-08-27 at 5.36.12 PM.png
Screen Recording 2026-08-27 at 5.36.12 PM.mp4
```

## 廣告

本應用程式免費，截圖完成後會在螢幕角落短暫顯示一個小橫幅。點 ✕ 關閉。
