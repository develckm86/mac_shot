# MacStyleCapture 0.4.6 — Atajos

Vive en la bandeja. No abre ninguna ventana.

## Atajos

| | |
| --- | --- |
| `Ctrl+Shift+3` | Capturar toda la pantalla — un archivo por monitor |
| `Ctrl+Shift+4` | Arrastra para capturar una zona — Space elige una ventana |
| `Ctrl+Shift+5` | Herramientas — captura de ventana, grabación, opciones |
| `Ctrl+Alt+Shift+3 / 4` | Portapapeles |
| `Ctrl+Alt+Esc` | Detener la grabación |

## Teclas que puedes mantener al arrastrar

| | |
| --- | --- |
| `Space` | Mueve la selección sin cambiar su tamaño |
| `Shift` | Solo cambia el último eje que moviste |
| `Alt` | Redimensiona simétricamente desde el punto inicial |
| `Ctrl` | Si la mantienes al soltar, va al portapapeles y no a un archivo |
| `Esc` | Cancelar |

## Opciones — `Ctrl+Shift+5` → Opciones

- **Guardar en**: Escritorio · Documentos · Portapapeles · Imágenes · Otra ubicación…
- **Temporizador**: Ninguno · 5 segundos · 10 segundos
- **Micrófono**: Ninguno · …
- **Opciones**: Mostrar miniatura flotante · Recordar la última selección · Mostrar el puntero · Mostrar clics del ratón · Preguntar dónde guardar
- **Idioma**: Idioma del sistema · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어

