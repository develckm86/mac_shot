# 스크린샷 0.3.0 — Scorciatoie

Resta nell'area di notifica. Non apre finestre.

## Scorciatoie

| | |
| --- | --- |
| `Ctrl+Shift+3` | Cattura tutto lo schermo — un file per monitor |
| `Ctrl+Shift+4` | Trascina per catturare un'area — Space sceglie una finestra |
| `Ctrl+Shift+5` | Strumenti — cattura finestra, registrazione, opzioni |
| `Ctrl+Alt+Shift+3 / 4` | Appunti |
| `Ctrl+Alt+Esc` | Ferma la registrazione |

## Tasti da tenere premuti durante il trascinamento

| | |
| --- | --- |
| `Space` | Sposta la selezione senza cambiarne le dimensioni |
| `Shift` | Cambia solo l'ultimo asse che hai mosso |
| `Alt` | Ridimensiona in modo simmetrico dal punto iniziale |
| `Ctrl` | Tenuto al rilascio: va negli appunti invece che in un file |
| `Esc` | Annulla |

## Opzioni — `Ctrl+Shift+5` → Opzioni

- **Salva in**: Desktop · Documenti · Appunti · Immagini · Altra posizione…
- **Timer**: Nessuno · 5 secondi · 10 secondi
- **Microfono**: Nessuno · …
- **Opzioni**: Mostra miniatura flottante · Ricorda l'ultima selezione · Mostra il puntatore · Mostra i clic del mouse · Chiedi dove salvare
- **Lingua**: Lingua di sistema · Deutsch · English · Español · Français · Italiano · Português · Tiếng Việt · Русский · 日本語 · 简体中文 · 繁體中文 · 한국어
